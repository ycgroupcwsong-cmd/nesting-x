ARRANGE VS NESTING X

기본 Arrange로 배치했다면,
이제 생산 수량과 자재까지.

기본 Arrange는 구성요소를 원판 위에 배치하는 도구입니다.
Nesting X는 필요한 수량, 원판 사용량, 배치 검사까지 함께 확인하도록 돕습니다.

비교 항목Fusion 기본 ArrangeNesting X의 장점

01 / 생산 수량부품마다 필요한
수량이 다를 때

기본 Arrange

선택한 구성요소의 배치가 중심입니다. 부품별 생산 수량을 지정하는 기능은 기본 Arrange에 포함되지 않아, 배치할 부품 수를 따로 준비해야 합니다.

Nesting X

파트 목록에서 부품별 수량을 입력해 네스팅하고, 목표 수량과 실제 배치 수량을 확인합니다.

수량에 맞춰 구성요소를 준비하는 반복 작업 감소

02 / 자재 판단배치에서 끝내지 않고
원판 사용량까지

기본 Arrange

기본 배치 결과만으로는 생산 수량에 따른 원판 소요량과 자재 활용도를 함께 관리하기 어렵습니다.

Nesting X

원판 규격·수량을 설정하고 사용 원판 수, 실사용 수율, 전체 수율을 결과에서 확인합니다.

몇 장을 쓸지, 얼마나 활용했는지 바로 확인

03 / 배치 검사배치한 다음
가공 여유까지 확인

기본 Arrange

기본 Arrange도 간격을 설정할 수 있습니다. 배치한 부품의 수량과 실제 가공 조건에 맞는 결과인지는 후속 확인이 필요합니다.

Nesting X

공구 지름·추가 간격·테두리 여유를 설정하고, 겹침·원판 이탈·간격 위반 등 검사 결과를 한 화면에서 확인합니다.

가공 전에 수정할 배치 문제를 찾기 쉽게

비교 기준 Fusion 기본 Arrange 기준입니다. Nesting X는 Fusion과 함께 사용하는 애드인이며, 배치 결과를 적용한 뒤 공구경로와 NC 코드는 CAM에서 설정합니다.

판재 절단 · 임가공

CNC 라우터·레이저 가공 담당자

여러 DXF를 받아 절단을 준비할 때, 보유 원판의 규격과 가공 여유를 기준으로 부품을 배치하고 Fusion에서 후속 CAM 작업을 이어갈 수 있습니다.

다품종 소량 생산

원판 소요량을 산정하는 생산팀

주문마다 부품 수량이 달라지는 현장에서 원판 크기와 수량을 바꿔 보고, 어떤 자재를 몇 장 준비할지 판단할 수 있습니다.

어떤 공정에 적용하나요?

시연의 목재 스툴처럼 합판·MDF 부품을 CNC 라우터로 재단하는 작업, 평판 부품을 레이저로 절단하기 전 소재 배치를 검토하는 작업에 활용할 수 있습니다. 공구경로와 장비용 NC 코드는 후속 CAM 단계에서 준비합니다.

도입 시 기대 효과

절단 전에 달라지는 세 가지

원판을 더 쓸지 먼저 판단

배치안별 사용 원판 수와 수율을 비교해, 부품을 추가했을 때 기존 원판에 들어가는지 확인할 수 있습니다. 자재를 꺼내기 전에 남는 면적도 살펴볼 수 있습니다.

수작업 재배치 시간 절약

수량이나 원판 규격이 바뀌면 조건을 수정해 네스팅을 다시 실행합니다. 확정한 배치를 Fusion에 적용하므로 부품 위치를 하나씩 다시 잡는 작업을 줄일 수 있습니다.

가공 전 배치 오류 발견

목표 수량과 실제 배치 수량을 대조하고 겹침·원판 이탈·간격 위반을 확인합니다. CAM으로 넘기기 전에 수정할 부품을 찾을 수 있습니다.

기능과 사용법

작업 조건을 정하고,
Fusion에서 이어가세요.

  1. DXF 부품 불러오기

    가공할 평면 부품을 가져온 뒤 파트 목록에서 치수와 필요한 수량을 확인합니다.

  2. 원판과 배치 조건 설정

    원판의 폭·높이·수량·두께와 테두리 여유를 입력합니다. 공구 지름, 추가 간격, 회전 조건을 작업에 맞춥니다.

  3. 네스팅 실행 및 검사

    ‘시작’을 눌러 배치합니다. 미리보기에서 수율과 배치 수량을 확인하고 겹침, 원판 이탈, 간격 및 구멍 위반 여부를 점검합니다.

  4. Fusion에 결과 삽입

    ‘Fusion에 적용’을 누르면 원판 위 배치가 설계에 반영됩니다. 모델을 회전·확대해 부품의 위치와 슬롯을 확인합니다.
